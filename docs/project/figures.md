# About the terminal illustrations

The 17 terminal images in this library are explicitly retained **reference
figures** captured from the self-contained interface reference used during game
integration. They document the questions-first design and retained record
fields; they are not represented as pixel-identical captures of the final
released game.

Each image uses the full 480 × 270 logical-pixel monitor composition, captured at 2× scale (960 × 540 pixels). The usable inner opening is 393 × 219 logical pixels. The capture excludes the prototype’s external review controls and browser chrome. Still images pause cosmetic animation for legibility; the degauss example instead shows a moment during the effect.

Captions explain the relevant feature rather than treating the image as decoration. Main-case evidence and report images appear only in the spoiler-marked explanation. A screenshot does not substitute for selectable text: exact values and their interpretation remain in the surrounding article.

Current production captures of the title, Records Office, Nansen terminal, and
mobile full-screen presentation are kept separately in `docs/images/`. A
reference figure alone never proves production behavior or audio quality; the
release tests and public build are authoritative.
