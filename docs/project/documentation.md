# Documentation v1.0: one library, two reading experiences

The Markdown in this repository is the source of the documentation. It is organised for GitHub with relative links, tables of contents, and a short README. The same pages generate the documentation site, which adds a sidebar, page outlines, full-text search, and a filterable request catalog.

Neither version should contain different instructions or a more complete explanation of the evidence. The site improves navigation; it is not a place to hide documentation missing from the repository.

The library keeps the player guide and synopsis spoiler-free. Solution analysis and the optional token discovery have explicit warnings. Search excludes those sections unless the reader enables them.

The [Complete Script Explorer](../script/index.md) is generated from the
shipped story authority and runtime route registries. It is present in both
views, but its pages remain spoiler-marked and excluded from search until the
reader enables evidence/spoiler results. Its machine-readable
[coverage receipt](../script/SCRIPT_EXPLORER_COVERAGE.json) reports source
hashes, expected-versus-actual route totals, explicit non-dialogue exclusions,
and zero unexplained omissions.

The canonical library lives in the public
[repository](https://github.com/th3Wh1t3Rabbit/tarka/tree/main/docs). The same
Markdown generates the searchable
[documentation site](https://docs.tarka-meridian.workers.dev/), which links
back to the [game](https://play.tarka-meridian.workers.dev/) and
[release downloads](https://github.com/th3Wh1t3Rabbit/tarka/releases/tag/v1.0.0-meridian).
Anonymous desktop and mobile checks cover the site root, search, navigation,
deep links, images, and 404 behavior.
