# The Nansen request catalog

This catalog contains **101 retained request entries for Euler research**. Each page records the investigative question, endpoint family, selected-record associations, and available fingerprints. RQ identifiers are stable documentation references, not provider-issued request IDs or a new execution chronology.

> **Evidence appendix:** request questions and linked records may reveal case connections. The [player guide](../controls.md) remains spoiler-free.

Execution evidence is not uniform across all 101 entries. The final 76-request expansion has exact canonical request bodies, endpoint paths, body hashes, result counts, raw/normalized/terminal hashes, hashed provider IDs, credit fields, and per-call independent acceptance. The earlier 25 accepted Euler receipts expose public call IDs, endpoint families, bounded questions, request/response/normalized hashes, result counts, temporal class, and acceptance status, but this admitted slice does not expose every original body, execution timestamp, terminal commitment, or hashed provider ID. Archive index order is not presented as execution chronology.

The missing execution timestamps and provider IDs for the earlier 25 rows were
not retained in the public-safe slice. They remain unavailable; no body,
timestamp, provider identifier, or chronology is inferred from the questions.

Original responses remain private; selected public fields and hashes retain traceability. [How these counts differ](counts.md).
