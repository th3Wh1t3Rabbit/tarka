# Beyond this case

The question-led terminal and evidence model suggest a format that could be reused for another carefully selected historical case. A hypothetical second mission would need its own evidence, narrative, and validation; it is not an included or promised part of this release.

For now, the useful result is a complete small adventure and an example of how to turn directed inquiry into a navigable dataset. The next idea can wait until this one has had its chance to be played.
