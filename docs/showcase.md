# Watch the investigation

The showcase brings together the Records Office, Rook and Arthur's exchanges, a useful Nansen-powered inquiry and a glimpse of the terminal's personality. It is a short invitation to play, not a walkthrough of the solution.

## What the highlights show

A question is the turning point: a large collection becomes a smaller set of relevant records. The footage pairs that investigation with the tactile office actions and dry humor that frame it. The underlying evidence is a saved historical collection; a terminal query in the video is not a new live API request.
