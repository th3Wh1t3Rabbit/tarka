## Read the writing

The [Complete Script Explorer](script/index.md) is generated from the shipped
script authority and effective runtime routes. It maps all final story panels,
hotspot verbs, ordered inventory combinations, Arthur dialogue states,
terminal speech, optional branches, endings, timing, and performance cues.
The [coverage receipt](script/coverage.md) binds those pages to source hashes
and records zero unexplained omissions.
