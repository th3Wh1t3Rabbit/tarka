# Release rights manifest

## MIT-designated first-party software

The surrounding implementation code and technical build documentation in
`src/`, `scripts/`, `tests/`, root configuration files, and technical Markdown
are MIT-designated, except for embedded creative content described below.

## Tarka creative content

The Tarka Content Terms cover original material under `public/art-packs/`,
`public/audio/`, narrative and dialogue values in `src/`, `content/`,
`fixtures/`, `public/scenarios/`, and creative screenshots, logos, character
descriptions, story text, and branding wherever embedded.

The four shipped audio files were created by the project owner and are
authorized for distribution with the official game:

- `public/audio/background-main.ogg`
- `public/audio/background-terminal.ogg`
- `public/audio/case-closed.ogg`
- `public/audio/degauss-sfx.mp3`

## Third-party and factual material

Third-party packages and the Probly8 font retain their own licenses. Public
facts, Ethereum transaction facts, Nansen-derived records, Nansen marks, Euler
Finance marks, and other third-party marks are not relicensed by Tarka.
