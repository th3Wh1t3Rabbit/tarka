Source snapshots and game content

Tarka's public release presents one complete reviewed source snapshot rather than the project's private development log. The public source, release downloads, hosted game, and hosted documentation are joined by the v1.0.0-meridian release and published checksums.

Reusing code is not reusing the game's art

Explicitly designated code is reusable under MIT, while the original artwork, animation, music, creative writing, character depictions, and branding are covered by the Tarka Content Terms. Someone reusing the code needs their own content or separate permission for Tarka's content. Third-party dependencies and provider data keep their original terms.

The Script Explorer presents the game's creative writing for readers; its inclusion in documentation does not itself give that writing a permissive software license. Viewing the public repository or making a GitHub fork is distinct from permission to extract and reuse its content in another game.

The adopted rights manifest classifies by path and embedded content rather than assuming that every .ts, .json, or .md file has one license category. The licensor is th3Wh1t3Rabbit.
