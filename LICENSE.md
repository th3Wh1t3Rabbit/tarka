# Tarka licensing

Tarka uses a split license.

- First-party software code and technical documentation explicitly identified
  in [RIGHTS_MANIFEST.md](RIGHTS_MANIFEST.md) are licensed under the
  [MIT License](LICENSE-CODE-MIT.md).
- Original Tarka artwork, sprites, animation, music, narrative, dialogue,
  characters, logos, branding, and other creative content are covered by the
  [Tarka Content Terms](LICENSE-CONTENT.md).
- Third-party software, font material, public facts, Nansen-derived records,
  and third-party marks retain their own terms. See
  [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

The presence of creative content inside a TypeScript, JSON, Markdown, or other
source file does not change that content into MIT-licensed material.
